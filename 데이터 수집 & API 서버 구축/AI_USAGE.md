# AI 사용 기록

AI는 개념 질문과 직접 작성한 코드의 디버깅에만 사용할 수 있습니다. 사용하지 않았다면 아래에 `사용하지 않음`이라고 적습니다. 사용량을 늘릴 필요는 없습니다.

| 허용되는 도움 | 예시 |
|---|---|
| 개념 이해 | HTTP 404와 422의 차이, await의 의미를 다른 예시로 설명해 달라고 질문 |
| 자신의 코드 디버깅 | 직접 작성한 짧은 함수와 오류를 보여 주고 원인과 확인 방법을 질문 |

과제 전체 풀이, TODO의 완성 코드, 참고 답안을 요청하지 않습니다. 디버깅 답변도 이해한 원인과 수정 내용을 자신의 말로 기록하고 다시 실행합니다. API 키, `.env`와 인증 헤더를 질문에 포함하지 않습니다.

## 사용 여부

- 사용 여부: 사용함 (구현 힌트, 디버깅 원인 질문, 작성 메모 방향 질문)
- 사용한 도구: Claude Code (Sonnet 5.5)

## 도움 기록

도움을 받은 건마다 표의 행을 추가합니다. 대화 전문보다 질문과 직접 확인한 결과를 구체적으로 적습니다.

| 단계/함수 | 직접 시도한 내용과 문제 | 질문 요약 | 받은 설명 | 내가 수정하거나 확인한 내용 | 재실행 결과 |
|---|---|---|---|---|---|
| 전체 | 빈칸 위치와 확인 방법을 모름 | 수정 위치와 check 명령 질문 | 빈칸 위치 표, `run`/`check` 명령 안내 | 안내대로 단계별 실행 | |
| collect_releases | check 9개 전부 실패 | 원인 질문 | 저장 코드가 반복 변수 대신 report 고정이라는 지적 | json.dump 첫 인자를 반복 변수로 수정 | 통과 |
| normalize_releases | 정상 문서가 격리됨, name None/공백 처리 불확실 | 원인과 제목 대체 조건 질문 | 빈 본문 조건 방향 반대, name None이면 strip 오류, `or " "`는 항상 참 | 빈 본문 조건 반전, name 문자열 확인 후 strip | 통과 |
| Document/QueryRequest | category 허용값 위치를 못 찾음, session_ids 오타 | 허용값 위치와 오류 질문 | ASSIGNMENT.md 71·131행 안내, 필드명은 session_id | 허용값 반영, 필드명 수정 | 통과 |
| register_document | any 구문 예시 요청, `.get()` 사용 | 구문 예시와 오류 질문 | 유사 예시, 모델 객체는 점(.)으로 필드 접근 | `.source_url`로 수정 | 통과 |
| call_model_once | ValidationError, 출처 검사 방법 모름 | 원인 질문 후 정답 직접 요청 | json.loads 필요, any로 선택 밖 출처 검사 (완성 코드를 직접 받음) | 두 줄을 받은 대로 적용 | |
| admit_query | 31번째 요청이 거부되지 않음 | 실패 원인 질문 | now와 window를 직접 비교, 경과 시간은 now - start | 구간 갱신 조건 수정 | |
| 작성 메모 | GET/POST와 404/422, await와 2회 시도, API 사용 이유 의미 불확실 | 메모 의미와 방향 질문 | 개념 설명과 쓸 거리 힌트 | 내용을 직접 작성 | |
